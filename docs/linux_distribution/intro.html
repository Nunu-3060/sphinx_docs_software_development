1. はじめに

1.1. 本文書の目的

Linux を使うシステムを構築する際、最初に決める事項の一つがディストリビューションの選択である。ディストリビューションごとにパッケージ管理、リリース周期、サポート期間、標準のセキュリティ機構などが異なり、その選択はシステムの運用負荷や将来の移行計画に長く影響する。

本文書は、代表的な Linux ディストリビューションについて概要・歴史・相互の違いを整理し、用途に応じたディストリビューションを選定するための判断材料を提供することを目的とする。

1.2. 対象読者

Linux の基本的なコマンド操作の経験があるエンジニアを対象とする。特定のディストリビューションしか使ったことがない読者が、ほかのディストリビューションとの違いを把握する用途も想定している。

1.3. 扱う範囲

本文書では次の内容を扱う。

  • サーバ・クラウド・デスクトップで広く使われているディストリビューションと、系統の起点となったディストリビューション

  • 各ディストリビューションの成り立ち、特徴、パッケージ管理、リリースとサポートの方針

  • ディストリビューション間の比較と選定の観点

次の内容は扱わない。

  • インストール手順や個別ソフトウェアの設定方法

  • 組込み機器向けのビルドシステム（Yocto Project など）や、Android、ChromeOS などの Linux カーネルを採用した OS

  • 市場シェアの数値（信頼できる統一的な統計が存在しないため）

1.4. 情報の時点

バージョンやサポート期限などの情報は、2026 年 10 月時点の各プロジェクト・企業の公開情報に基づいて記載している。サポート期限は変更されることがあるため、実際の選定や移行計画では参考文献に挙げた公式情報を確認すること。
