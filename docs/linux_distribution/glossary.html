用語集

ABI 互換

アプリケーションバイナリインタフェース（ABI）が互換であること。ABI 互換のディストリビューション間では、一方向けにビルドしたバイナリがもう一方でも動作する。不具合を含めて同じ挙動となることまでは保証しない点で、バグ互換とは異なる。

AppArmor

Linux カーネルのセキュリティモジュールの一つで、プログラムごとにアクセスできるファイルなどをパスに基づいて制限する。Debian、Ubuntu などで標準的に使われている。

glibc

GNU C Library。GNU プロジェクトが開発する C ライブラリで、多くのディストリビューションが採用している。

LTS

Long Term Support の略。通常より長い期間サポートされるリリースのこと。

musl

軽量で標準規格への準拠を重視した C ライブラリ。Alpine Linux などが採用している。

SELinux

Security-Enhanced Linux。Linux カーネルのセキュリティモジュールの一つで、プロセスやファイルに付与したラベルに基づいてアクセスを制限する。RHEL 系などで標準的に使われている。

systemd

多くのディストリビューションで標準となっている init システムとシステム管理ツール群。サービスの起動と管理のほか、ログ管理（journald）やネットワーク設定（systemd-networkd）などの機能を持つ。

アップストリーム

ソフトウェアの開発元、または変更の流れの上流にあたるプロジェクト。

イミュータブル OS

システム領域を読み取り専用とし、OS イメージ全体を単位として更新する OS。更新の失敗による不整合が起こりにくく、更新前の状態に戻しやすい。

サブスクリプション

一定期間ごとに料金を支払い、ソフトウェアの更新や技術サポートを受ける契約形態。

ダウンストリーム

アップストリームのソフトウェアを取り込んで配布する側、または変更の流れの下流にあたるプロジェクト。

ディストリビューション

Linux カーネルと、OS として利用するために必要なソフトウェアを組み合わせ、インストーラやパッケージ管理の仕組みとともに配布するもの。

バグ互換

不具合を含めて、元のソフトウェアと同じ挙動となること。bug-for-bug 互換とも呼ぶ。

パッケージ管理システム

ソフトウェアをパッケージとして導入・更新・削除し、パッケージ間の依存関係を管理する仕組み。

ポイントリリース

固定リリースのディストリビューションで、同じバージョンの中で修正や更新をまとめて公開する版。マイナーリリースとも呼ぶ。

リビルドディストリビューション

商用ディストリビューションの公開ソースコードからバイナリを再構築し、互換性を持たせたディストリビューション。クローンとも呼ぶ。

リポジトリ

パッケージを集めて配布するサーバ、またはその保管場所。

ローリングリリース

バージョンの区切りを設けず、パッケージを継続的に最新版へ更新するリリースモデル。
