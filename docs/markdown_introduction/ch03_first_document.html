3. はじめての Markdown 文書

この章では、細かい規則はいったん置いて、短い自己紹介の文書を 1 つ書いてみる。Markdown でどのように文書を書くのか、全体の流れをつかむことが目的である。ここで使う記法の詳しい規則は、第 4 章以降で説明する。

3.1. ファイルを作る

VS Code で新しいファイルを作り、self_introduction.md という名前で保存する。保存したら、第 2 章で説明した Ctrl+K の後に V の操作で、プレビューをエディタの横に開いておく。

3.2. 見出しと段落を書く

まず、文書のタイトルと最初の文章を書く。

書き方

1# 自己紹介
2
3はじめまして。プログラミングを学び始めて 3 か月になる。

表示結果（CommonMark）

自己紹介

はじめまして。プログラミングを学び始めて 3 か月になる。

1 行目のように行頭に # と空白を書くと、その行は見出しになる。3 行目のように記号を付けずに書いた文章は段落になる。見出しと段落の間には空行を 1 行入れる。

3.3. 項目を並べる

次に、小見出しを付けて、好きなものを箇条書きで並べる。

書き方

1## 好きなもの
2
3- コーヒー
4- 散歩
5- 本を読むこと

表示結果（CommonMark）

好きなもの

  • コーヒー
  • 散歩
  • 本を読むこと

# を 2 個にすると、1 段下のレベルの見出しになる。行頭に - と空白を書くと、その行は箇条書きの項目になる。

3.4. 文字を強調する

箇条書きの 2 番目の項目に説明を加え、一部を目立たせる。

書き方

1- コーヒー
2- **散歩**（毎朝 30 分歩く）
3- 本を読むこと

表示結果（CommonMark）

  • コーヒー
  • 散歩（毎朝 30 分歩く）
  • 本を読むこと

** で挟んだ部分は強調され、太字で表示される。

3.5. リンクを張る

最後に、もう 1 つ小見出しを加え、Web ページへのリンクを含む文章を書く。

書き方

1## 今学んでいること
2
3いまは Python を学んでいる。教材には [Python の公式チュートリアル](https://docs.python.org/ja/3/tutorial/) を使っている。

表示結果（CommonMark）

今学んでいること

いまは Python を学んでいる。教材には Python の公式チュートリアル を使っている。

[ と ] で囲んだ文字がリンクとして表示され、その直後の ( と ) で囲んだ URL がリンク先になる。

ここまでの内容をまとめると、次のような文書になる。このファイルは ch03_first_document.md からダウンロードできる。

今学んでいること

ソースを読み返すと、使った記号は #、-、**、[]() の 4 種類だけである。それでも、見出しで区切られ、箇条書きと強調、リンクを含む、整った文書になっている。
